# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Renamed all client and server class / files. They used to be named as tp-server and tp-client, they are now do not contain such indexes.
2. Added voice-talk support for the new UI that replaces tpz_menu_base in order to support voice chat while NUI is active.
3. Fixed a wrong locale that was sent when the owner attempted to transfer the apiary ownership to himself / herself. The notification was not the correct one.
4. Many notifications have been updated to use TP Notify instead of the default RDR notification system. This change was made possible by the new NUI system, which provides better integration and allows TP Notify to be used more efficiently, resulting in a more consistent and improved notification experience.
5. Added apiary progress leveling system for unlocking more benefits on a placed apiary.
6. Added maximum members for being able to assist on an apiary than having no limit. To increase the limit, you can do through the apiary level benefits - progression.
7. Added maximum insects that was based on the apiary model, to be based on the apiary level benefits - progression.
8. Reworked the placed apiary unique ID generator to use a more secure and collision-resistant generation method.
9. Added a new feature to display near beehives (blip) to players when being close with job support as an optional requirement.
10. Created a new file on server directory folder named as `api.lua`, this is a new file for Developers API in case they want to use the apiary and player leveling systems.
11. Added a new feature for the apiary model to change on level up (totally optional), this is in case you want the apiaries to actually have a visible "upgrade". by changing their model based on the level.
12. Added invitation dialog nui when a player wants to add member to the apiary, it no longer adds the member automatically but it sends a request instead.
13. Added target-eye script support for accessing an apiary management menu, we support ox_target by default but in case you want to use your own, you can do it through `client/escrow_ignore.lua` file.
14. Added builder NUI when placing an apiary than using the 3DText that was located on the screen, you are now will be having a builder (checkout screenshots).
15. Fixed a bug with the apiary protection system where dead parasite data was not reset when new protection was added, causing the new protection to incorrectly use the previous protection's parasite count.
16. Deleted `server/items.lua` file, this was a registration of the sponge and jar attachments which are no longer gonna be used as usable items for attaching the sponge and the jar but will be automatically attached by the system instead.
17. Added extra item images on [EXTRA] directory folder.
18. Added an `items - readme.txt` file on [EXTRA] directory folder to register all items automatically on the database than manually.

## Modified Files:

- client folder **full replacement.**
- server directory folder **full replacement**.
- html **add directory folder and its contents.**
- locales.lua **full replacement**.
- fxmanifest.lua

3. Add the new option on the `config.lua` file below `Config.BeehiveActionsDuration` option which is related to beehives for displaying a blip on players who are near.

```lua
-- Would you like to display a blip when being near beehives to players? (Not apiaries)
Config.DisplayNearBeehiveBlip = {  -- 2.0.7
    Enabled    = true, 
    BlipSprite = 1453767378,
    Name       = "Beehive",

    Distance   = 70.0,

    -- Set Jobs = false to allow everyone to be able to see a beehive blip nearby.
    -- Otherwise, use a table form { 'job1', 'job2' } to display near beehives to specific jobs only.
    Jobs = {
        'beekeeper'
    },
} 
```

4. Add the new target-eye config option on `Config.ApiarySettings` configuration, below `PTFX`.

```lua
    -- Would you like to use a target-eye script for opening the apiary management menu?

    -- client/escrow_ignore.lua file.
    TargetEye = true, -- version 2.0.7
```

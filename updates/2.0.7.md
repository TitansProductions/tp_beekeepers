# What has been updated?

## Changelog - (Added, Fixed, Removed):

1. Renamed all client and server class / files. They used to be named as tp-server and tp-client, they are now do not contain such indexes.
2. Added voice-talk support for the new UI that replaces tpz_menu_base in order to support voice chat while NUI is active.
3. Fixed a wrong locale that was sent when the owner attempted to transfer the apiary ownership to himself / herself. The notification was not the correct one.
4. Many notifications have been updated to use TP Notify instead of the default RDR notification system. This change was made possible by the new NUI system, which provides better integration and allows TP Notify to be used more efficiently, resulting in a more consistent and improved notification experience.
5. Added apiary progress leveling system for unlocking more benefits on a placed apiary.
6. Added maximum members for being able to assist on an apiary than having no limit. To increase the limit, you can do through the apiary level benefits.

## Modified Files:

- client folder **full replacement.**
- server directory folder **full replacement**.
- html **add directory folder and its contents.**
- locales.lua
- fxmanifest.lua

## Notes

1. Add the new configuration options on config.lua file on General Settings section.

```lua
-- Set to true if you are NOT using saltychat / teamspeak but you are using another voice script that blocks NUI voice, if you set it to true
-- it will enable a system which allows the players to hear you while you are having the NUI active.
Config.PushToTalkFunction = true -- 1.3.2

-- (!) Checkout client/escrow_ignore.lua for adding more keys manually.
Config.HorseWhistleKey = 0x24978A28 -- (H BY DEFAULT) 1.3.2

-- (!) Checkout client/escrow_ignore.lua for adding more keys manually.
Config.WagonWhistleKey = 0xF3830D8E --  (J BY DEFAULT) 1.3.2
```

2. Add on `Config.Apiaries` on every apiary, the new features:

```lua

-- FROM

-- The specified apirary models will be able to be used and placed on the desired position. 
Config.Apiaries = { 

    [1] = { 
        Label      = 'Apiary Model (1)', 
        ModelName  = "bee_house_gk_1", 
        Item       = 'apiary_bee_house_gk_1',

        -- How many bees or hornets should the specified Apiary Model can carry? more insects, more product will be produced.
        -- (!) If an apiary has been already placed and you want to chance the maximum insects
        -- you have to manually edit directly from the sql based on the apiary Id while server or script is offline.
        MaximumInsects = 500,
        
    },
}

-- TO

-- The specified apirary models will be able to be used and placed on the desired position. 
Config.Apiaries = { 

    [1] = { 
        Label      = 'Apiary Model (1)', 
        ModelName  = "bee_house_gk_1", 
        Item       = 'apiary_bee_house_gk_1',

        -- How many bees or hornets should the specified Apiary Model can carry? more insects, more product will be produced.
        -- (!) If an apiary has been already placed and you want to chance the maximum insects
        -- you have to manually edit directly from the sql based on the apiary Id while server or script is offline.
        --MaximumInsects = 500, -- NOT SUPPORTED, CHECKOUT @Leveling section - it is now based on apiary level progression.

        --- @param RequiredPlayerLevel - Requires beekeeping player level for being able to place this apiary model.
        RequiredPlayerLevel = 1, -- version 2.0.8

        -- What is the maximum level this apiary model can reach?
        TotalApiaryLevels = 10, -- version 2.0.8

        LevelBenefits = { -- version 2.0.8

            [1] = { -- #1 Is default level on apiary placement.

                -- How many bees or hornets should the specified Apiary Model can carry? more insects, more product will be produced.
                -- For the feature information, read @MaximumInsects above (the mentioned option is no longer supported)
                MaximumInsects = 500,  

                -- How many members can join to assist on the specific apiary on this progression level?
                MaximumMembersWhoCanJoin = 0,

                -- This is based on @ProduceAmount feature, based on the apiary progression level, you can increase / multiply the produce amount.
                -- If you set / leave it to 1, it will not multiply and will use the default production.
                -- But in case you want to multiply, keep in mind the production amount is based on the apiary insects, that means (based on default @ProduceAmount),
                -- if you have 50-100 insects, the product amount is 8 by default, if you multiply more than (1), it will be 8 * multiplier (example, 8 * 1.5 = 12).
                -- This feature is how fast honey production will be ready.
                ProductAmountMultiplier = 1,

            },

        },
        
    },
}
```

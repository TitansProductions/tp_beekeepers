## Notes

If you don't want to replace `client/escrow_ignore.lua`, you can manually fix the issue #2 manually by changing on `AddApiaryActionTarget` function where `GetPlayerData().HasNUIActive` is located to also include if player is busy.

```lua

function AddApiaryActionTarget(apiaryId, object)
	
	local options = {
		{
			label    = Locales['APIARY_TARGET_ACTION'],
			icon     = 'fa-solid fa-eye',
			radius   = Config.ApiaryActionDistance,
			distance = Config.ApiaryActionDistance,

			onSelect = function(data)

                --if GetPlayerData().HasNUIActive then -- <- FROM
                if GetPlayerData().HasNUIActive or GetPlayerData().IsBusy then -- <- TO
                    return 
                end

				OpenApiaryManagementNUI(apiaryId)
			end,

		},

	}

	exports.ox_target:addLocalEntity(object, options)

end

```
